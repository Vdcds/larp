# PR1: Intelligent agent and PEAS

Source: [program](../pr1.txt) and [notebook](../pr1.ipynb). Revision: [PR1 cheat sheet](../CHEATSHEET.md#pr1-intelligent-agent-and-peas).

## Two-minute explainer

This program simulates a smart-home agent that controls an AC and a light. An agent receives information through sensors and takes actions through actuators. Here, Python generates the sensor readings instead of reading real hardware. The program then prints the actions rather than switching actual appliances.

PEAS describes the agent's task. P is the performance measure: comfort and energy saving. E is the environment: the smart home. A is the actuators: the AC and lights. S is the sensors: temperature and motion. The `peas` dictionary stores that description, and the first loop prints each entry. The dictionary describes the task; it does not make the decisions.

The temperature is a random integer between 20 and 35, including both ends. Motion is randomly chosen as `yes` or `no`. The agent turns the AC on only when the temperature is greater than 28. At exactly 28, the AC stays off. The light turns on when motion is `yes`. Each rule works independently, so the AC can be on while the light is off.

For a dry run, suppose the temperature is 30 and motion is `no`. The output says AC `ON` and light `OFF`. Another run can give different readings and therefore different actions.

This is a simple reflex agent because its action depends on the current reading and fixed condition-action rules. It does not remember earlier readings or learn a policy. Changing the threshold changes its behavior, but that is a manual rule change. The performance measure is a stated goal; this program does not calculate an energy-saving score.
