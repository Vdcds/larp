# PR5: Titanic preprocessing and EDA

Source: [program](../pr5.txt) and [notebook](../pr5.ipynb). Revision: [PR5 cheat sheet](../CHEATSHEET.md#pr5-titanic-preprocessing-and-eda).

## Two-minute explainer

This program prepares the Titanic dataset and explores its contents. It needs a local file named `Titanic-Dataset.csv`. The repository does not contain that file. The first steps display sample rows, shape, column information, summary statistics, and missing-value counts. These checks show what needs cleaning before a model can use the data.

The code fills missing `Age` and `Fare` values with their medians. A median is less affected by extreme values than a mean. It fills missing `Embarked` values with the most frequent category, removes duplicate rows, and drops `PassengerId`, `Name`, `Ticket`, and `Cabin`. Dropping `Cabin` also removes its remaining missing values from the feature table.

The program maps `Sex` to zero or one and one-hot encodes `Embarked`. One-hot encoding creates a separate indicator column for each embarkation category. `Survived` becomes the target `y`; the other columns become the input features `X`.

An 80/20 split separates training and test data. `StandardScaler` fits on the training subset and transforms both subsets using those training statistics. It scales `Age`, `Fare`, `SibSp`, and `Parch`. Standardization subtracts a training mean and divides by a training standard deviation. It does not put every value between zero and one.

The final steps print age, fare, and survival statistics and show histograms and boxplots. Histograms describe distributions; boxplots make spread and possible outliers visible. This program does not train or score a classifier.

One caveat is that the median and mode are computed before the split. For an honest model evaluation, learned preprocessing statistics must come from training data only. The scaler follows that rule, but the original imputation order does not. A preprocessing pipeline can keep the order correct.

Background: [scikit-learn's explanation of preprocessing leakage](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage).
