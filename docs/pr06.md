# PR6: Linear regression for housing values

Source: [program](../pr6.txt) and [notebook](../pr6.ipynb). Revision: [PR6 cheat sheet](../CHEATSHEET.md#pr6-linear-regression).

## Two-minute explainer

This program predicts a numerical housing value with linear regression. It loads California Housing, converts the feature array into a DataFrame, and adds the target as `Price`. The eight input features describe housing and location. Each row represents a census block group, so the target is a group's median house value rather than a particular house's sale price.

The code separates features `X` from target `y` and makes an 80/20 training and test split. `LinearRegression().fit(...)` learns an intercept and one coefficient per feature. Its prediction has the form `b0 + b1*x1 + ... + b8*x8`. Ordinary least squares chooses the coefficients to minimize squared training residuals.

The model predicts the test targets, and a table puts actual values beside rounded predictions. Evaluation still uses the unrounded `y_pred`. MAE is the mean absolute error. MSE averages squared errors and gives larger errors more weight. RMSE is the square root of MSE, returning the error to the target's units. R-squared compares squared error with a constant prediction based on the test targets' mean. It can be negative and is not a classification accuracy percentage.

The scatter plot compares actual and predicted values. Perfect predictions would lie along the diagonal where actual equals predicted. The last step predicts one supplied row. That row must keep the same feature order as training, which the named DataFrame columns help preserve.

The dataset's target unit is 100,000 US dollars. A prediction of `2.5` therefore means approximately $250,000 in the dataset's units. It is not a current property valuation. The first dataset load may need an internet download. Linear regression also does not prove that a feature causes a price change.

Dataset reference: [California Housing loader and target units](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.fetch_california_housing.html).
