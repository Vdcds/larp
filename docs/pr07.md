# PR7: Logistic regression and KNN

Source: [program](../pr7.txt) and [notebook](../pr7.ipynb). Revision: [PR7 cheat sheet](../CHEATSHEET.md#pr7-logistic-regression-and-knn).

## Two-minute explainer

This program compares two classifiers on the built-in Breast Cancer dataset. Each row contains numerical measurements, and the target has two labels: zero for malignant and one for benign. The code puts that target in `Result`, then separates the features from the labels. This is a classification exercise, even though one model has "regression" in its name.

The updated program creates an 80/20 train/test split with `random_state=42` and `stratify=y`. Stratification approximately preserves the class proportions. The original files omitted this step and tried to use undefined `X_train` and `X_test` variables. Both versions now create the split before scaling.

`StandardScaler` learns feature means and standard deviations from the training set. It uses those same statistics for the test set. This matters especially for KNN: a feature measured on a larger numerical scale can otherwise dominate distances. Scaling also helps logistic regression optimize its coefficients.

Logistic regression learns a linear score and converts it to a probability through the sigmoid function for this binary task. Its `predict` method returns a class label. KNN with `n_neighbors=3` looks at the three nearest training examples and uses their class votes. KNN stores examples rather than fitting a regression-style coefficient vector.

The program reports accuracy, precision, recall, F1, and confusion matrices, then compares accuracies in a bar chart. Confusion-matrix rows are actual classes and columns are predicted classes. Because malignant is label zero, the class-specific report is more useful than assuming label one means the condition of interest.

Finally, the code scales one test sample and asks both models for its label. The same preprocessing must apply to every new sample. A strong score on this teaching dataset is an evaluation result, not evidence that the program is ready for clinical decisions.
