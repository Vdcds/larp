# PR8: Gaussian Naive Bayes

Source: [program](../pr8.txt) and [notebook](../pr8.ipynb). Revision: [PR8 cheat sheet](../CHEATSHEET.md#pr8-gaussian-naive-bayes).

## Two-minute explainer

This program classifies Iris flowers with Gaussian Naive Bayes. It uses four measurements: sepal length, sepal width, petal length, and petal width. The target is one of three species. The built-in dataset provides both the numeric labels and their names, so `data.target_names` can label the report and confusion matrix.

The code displays sample rows and checks for missing values. It separates the features and target, then makes an 80/20 train/test split with `random_state=42`. This particular program does not request stratification. The model fits on training rows and predicts the labels of the held-out rows.

Naive Bayes uses Bayes' rule. For a class, the posterior probability is proportional to the class prior multiplied by the likelihood of the observed features. "Naive" refers to the assumption that features are conditionally independent given the class. It does not mean that every pair of features is independent in the whole dataset.

`GaussianNB` models each feature's distribution within a class with a Gaussian, or bell-shaped, density. Training estimates class priors and feature statistics. Prediction compares class scores and chooses the largest. The model can work well even when its independence assumption is imperfect, but that assumption still limits how it represents relationships between measurements.

The output includes actual and predicted labels, overall accuracy, a classification report, and a confusion matrix. The matrix has actual classes on rows and predicted classes on columns. Diagonal entries are correct predictions. Off-diagonal entries show which species the model confuses. The plotted display uses species names instead of requiring you to remember numeric labels.

The program uses `GaussianNB` because the inputs are continuous measurements. Other Naive Bayes variants target different data assumptions. A fixed split gives a repeatable demonstration; its accuracy is not a guarantee for every future sample.
