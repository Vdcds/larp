# PR9: K-means and hierarchical clustering

Source: [program](../pr9.txt) and [notebook](../pr9.ipynb). Revision: [PR9 cheat sheet](../CHEATSHEET.md#pr9-k-means-and-hierarchical-clustering).

## Two-minute explainer

This program groups Iris measurements without using the species labels during fitting. That makes clustering an unsupervised task. The DataFrame begins with the four measurement columns. `StandardScaler` standardizes them so that the distance calculations do not depend mainly on a feature's numerical scale.

The first loop fits K-means for cluster counts one through ten. It collects `inertia_`, the sum of squared distances between samples and their assigned centroids. This is also called within-cluster sum of squares, or WCSS. The elbow plot looks for a point after which more clusters give smaller improvements. It is a visual aid, not an automatic proof of the correct count. The program later sets the cluster count to three explicitly.

K-means alternates between assigning points to nearby centroids and updating those centroids. `n_init=10` tries ten initializations and keeps the best result by inertia. `random_state=42` makes that randomized initialization repeatable. `fit_predict` returns a cluster number for each sample.

The second method is agglomerative hierarchical clustering. It starts with separate samples and repeatedly merges clusters. Ward linkage chooses merges that minimize the increase in within-cluster variance. The dendrogram shows that merge hierarchy, and the final model stops at three clusters.

The program plots both results using petal length and petal width. The models actually fit all four standardized measurements, so each scatter plot is only a two-dimensional view of the result.

Cluster IDs are arbitrary names. Cluster zero is not automatically Iris species zero, and the IDs from the two algorithms need not align. This program prints group counts and displays structure; it does not calculate classification accuracy. Adding cluster columns to `df` does not change the earlier `X_scaled` array used for fitting.

Background: [Ward linkage in scikit-learn](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.AgglomerativeClustering.html).
