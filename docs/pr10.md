# PR10: PCA before classification

Source: [program](../pr10.txt) and [notebook](../pr10.ipynb). Revision: [PR10 cheat sheet](../CHEATSHEET.md#pr10-pca).

## Two-minute explainer

This program compares digit classification with and without principal component analysis, or PCA. The Digits dataset represents each eight-by-eight image as 64 numerical features. The labels identify the digits zero through nine. A stratified 80/20 split keeps class proportions approximately similar in training and test data.

The baseline pipeline contains `StandardScaler` followed by `LogisticRegression`. Calling `fit` teaches the scaler and classifier from the training data. Calling `predict` applies the stored scaling to the test features before classification. A pipeline keeps those steps together.

The second pipeline inserts `PCA(n_components=0.95)` between scaling and classification. PCA finds perpendicular directions that capture variation in the training features, then projects the data onto selected directions. A principal component is a weighted combination of original features, not an original pixel chosen from the image.

The value `0.95` is a variance-retention target. It is not a request for 95 components or 95 percent accuracy. PCA keeps enough components to retain at least 95 percent of the training variance under this setting. The program reads the fitted component count from `pca_model.named_steps["pca"].n_components_`. Standardization is a separate step because PCA centers inputs but does not automatically standardize every feature.

Both classifiers predict the same held-out test set, and the code compares their accuracies. Fewer dimensions may remove redundancy, but discarded information can also hurt classification. PCA does not use the digit labels when choosing directions. High variance is not the same thing as strong class separation.

A separate PCA with two components creates the colored scatter plot from training data. That plotting model is different from the 95-percent-variance model used for classification. The colors show known training labels after projection; they do not mean PCA learned those classes.

Background: [scikit-learn's PCA guide](https://scikit-learn.org/stable/modules/decomposition.html#pca).
